# NENA NG9-1-1 GIS Data Model templates

`NG911_GISDataModelTemplate_v3.0.gpkg` is NENA's prebuilt v3.0 GeoPackage template, copied unchanged from
[NENA911/NG911GISDataModel](https://github.com/NENA911/NG911GISDataModel)
(`flatfile_templates/prebuilt_templates/v3.0/`), Apache License 2.0 (`LICENSE-NENA.md`). `export.py` writes a
statewide GeoPackage into a copy of it, so layer names, field names, types and length checks are NENA's own.

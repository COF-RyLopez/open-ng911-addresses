# Open NG9-1-1 address packages

Open-data NENA NG9-1-1 address packages for the 911 authorities of the US and Canada, Overture release 2026-11-18.0. Only Packages whose every source is openly licensed and whose 911 authority has opted in carry data here; the scorecard lists every Package.

- [Package scorecard](./scorecard/collection.json)
- [Canada: NG9-1-1 Packages](./ca/catalog.json)

Licence: each collection states its own; data keeps its sources' licences (README of each collection).
Provenance: built by [open-ng911-addresses](https://github.com/COF-RyLopez/open-ng911-addresses) from government sources and Overture addresses.

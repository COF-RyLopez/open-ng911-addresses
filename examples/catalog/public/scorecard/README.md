# Package scorecard

Every Package built for Overture release 2026-11-18.0, 4 in all and 2 published here: counts, GERS coverage, licence and opt-in state, on each county or census division outline. Withheld Packages appear here with their reasons and no address data.

Licence: the outlines are Statistics Canada census divisions (Statistics Canada Open Licence), Census TIGER counties (public domain); the counts are the project's own.
Provenance: each build job's manifest.json, from [open-ng911-addresses](https://github.com/COF-RyLopez/open-ng911-addresses).
